# langgraph-streamlit-chatbot
A basic chatbot built with LangGraph and Streamlit to learn how to connect LangGraph workflows/agents with a frontend UI and integrate an LLM into an interactive chat application.


A basic chatbot built using **LangGraph** with **Streamlit** as the UI.

## 🎯 Purpose

This project was built mainly to learn how to **connect a LangGraph workflow/agent with a Streamlit frontend** and understand the basic flow between the UI and backend.

## 🛠️ Tech Stack

* Python
* LangGraph
* LangChain
* Groq / LLM
* Streamlit

## 🔄 How It Works

**User → Streamlit UI → LangGraph → LLM → Response → Streamlit UI**

The user enters a message in Streamlit, which is passed to the LangGraph workflow. The graph processes the message using the LLM and returns the response back to the UI.

## 🚀 What I Learned

* Creating a basic LangGraph workflow
* Connecting an LLM with LangGraph
* Managing chatbot messages
* Integrating LangGraph with Streamlit
* Building a simple LLM application UI

## 📌 Note

This is a **learning project**, created to understand the fundamentals of connecting **LangGraph agents/workflows with a frontend UI**. It is intentionally simple and serves as a foundation for building more advanced agentic applications.
